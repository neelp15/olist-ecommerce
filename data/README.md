# Data

Download the dataset from Kaggle: search for **"Brazilian E-Commerce Public Dataset by Olist"**
(free Kaggle account needed). Unzip and put these CSV files in this folder:

- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_reviews_dataset.csv
- olist_order_payments_dataset.csv
- olist_customers_dataset.csv
- olist_products_dataset.csv
- product_category_name_translation.csv

The CSV files are git-ignored because of their size.
